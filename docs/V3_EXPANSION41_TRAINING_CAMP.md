# Expansion 41 — Focused skill camp

The Offseason page now includes an interactive Development Facility. Choose shooting, playmaking, defense, or rebounding work for up to three healthy, non-synthetic roster players. Player cards show current skills, overall, age, and potential. Cards adapt between one and two columns. Preview displays exact deterministic outcomes and their opportunity costs; confirmation applies those outcomes to the V3 working checkpoint. The system is available only during offseason, once per season across the league.

CPU teams select up to three players by potential gap and age and train their weakest supported skill with the same bounded model. Youth and potential headroom influence gains; gains cannot exceed 1.5 focused skill points, and successful focused work costs up to 0.25 points in a different skill. Ratings, simulation stat factors, and baseline production change together using the existing development conversion. Potential, age, contracts, and annual development remain unchanged by camp. Separate player camp history avoids changing the service-time fallback used by annual history. League results persist in checkpoint preferences, keyed by season.

Presentation includes existing portrait components, skill bars, before/after results, a short result fade, and an optional synthesized two-note chime. Sound is off by default and its setting lasts for the current component session. This is a focused skill camp, not a summer-league game simulator or a full mentorship, staff-budget, morale, or role-promise system. Those remain future work.

Save boundary: preview writes nothing. Execution requires the current working-save SHA-256, builds a deep-copy candidate, writes and reloads a temporary checkpoint, validates outcomes, verifies source/protected hashes, creates a hash-verified recovery copy, then atomically replaces the working save. Existing automatic backup is retained. Protected V2 is never written. A repeated camp or stale preview is rejected. No camp was executed against the user's live save during development.
